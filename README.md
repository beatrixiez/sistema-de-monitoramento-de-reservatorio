### 🎯 Objetivo:

#### Este simples programa exibe mensagens de alerta com cores diferentes, conforme o nível de água do reservatório.

#### Nível 1 = Muito baixo (crítico) 🔴
#### Nível 2 = Baixo 🟡
#### Nível 3 = Médio 🟢
#### Nível 4 = Alto 💠
#### Nível 5 = Muito alto (alerta) 🔵

### 🛠 Ferramentas:

#### A linguagem utilizada para desenvolvimento foi **Python**. Assim como as bibliotecas **colorama**, **random** e **time**.

### 👩🏻‍💻 Execução:

#### Direto no terminal da IDE ou no Prompt de Comando do computador.
